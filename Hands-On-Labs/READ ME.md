# Hands-On SOC Labs

## Overview

This folder contains my practical cybersecurity exercises and hands-on SOC Analyst training labs.

The objective is to apply theoretical knowledge in real-world-like environments, develop practical security analysis skills, and gain experience with tools and techniques commonly used by Security Operations Center (SOC) analysts.

## Lab Categories

### 1. Windows Security Monitoring
- Windows Event Log analysis.
- Monitoring authentication activities.
- Investigating failed and successful login attempts.
- Identifying suspicious account activities.
- Analyzing security-related Event IDs.

### 2. Linux Log Analysis
- Exploring Linux system logs.
- Analyzing authentication logs.
- Investigating failed login attempts.
- Monitoring suspicious system activities.
- Using Linux commands for log investigation.

### 3. SIEM Monitoring and Analysis
- Understanding SIEM log collection.
- Monitoring security events.
- Investigating generated alerts.
- Understanding detection rules and correlation.
- Working with security monitoring platforms.

### 4. Threat Intelligence and IOC Investigation
- Investigating suspicious IP addresses.
- Analyzing suspicious domains and URLs.
- Checking file hashes and indicators of compromise.
- Using threat intelligence platforms.
- Documenting investigation findings.

### 5. Incident Investigation
- Security alert triage.
- Investigating suspicious activities.
- Analyzing potential phishing attempts.
- Understanding malware-related indicators.
- Documenting incidents and investigation results.

## Lab Documentation Format

Each lab will follow a consistent documentation structure:

| Section | Description |
|---|---|
| Objective | Purpose of the lab |
| Environment | Operating system and tools used |
| Scenario | Security scenario being investigated |
| Procedure | Steps performed during the lab |
| Commands | Commands, queries and configurations |
| Findings | Observed events and investigation results |
| Analysis | Technical explanation of findings |
| Conclusion | Final outcome and lessons learned |
| Evidence | Screenshots, logs and supporting files |

## Learning Objectives

Through these hands-on labs, I aim to develop practical skills in:

- SIEM operations and alert investigation.

- Identifying suspicious activities.
